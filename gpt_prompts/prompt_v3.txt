You are extracting data from a faxed medical Service Request Form (SRF). The page may be skewed, noisy or low resolution. Read carefully.

  RULES:
  1. Copy values exactly as printed. Never guess, infer, or complete a partial value.
  2. If a field is blank, unreadable or absent, use null (or [] for diagnoses/procedures).
  3. Use only the value next to a field's own label. Do not copy a value from a neighbouring section
     (e.g. the requesting provider's phone must not be reused as the servicing provider's phone).
  4. Dates: write MM/DD/YYYY exactly as the form's US month/day order, e.g. 03/16/2026. Expand a 2-digit
     year to 4 digits. If any part of the date is unreadable, use null. Do NOT use YYYY-MM-DD.
  5. Codes, NPIs, member IDs: copy the characters printed; spaces are fine to drop. An NPI has exactly
     10 digits; if you cannot read all 10, use null.
  6. Phone and fax are different fields: read the label ("Phone"/"Tel" vs "Fax") before assigning.
  7. Checkbox fields: return the label of the marked box; if none is marked, use null.
  8. numberOfVisits is a whole number (e.g. 12), not text.
  9. Lists: one object per row actually printed, in page order. Do not merge rows and do not invent rows.

  FIELD GUIDE:
  - member_name, member_id, date_of_birth: patient/member section.
  - requesting_provider_*: the ordering/referring provider (labels like Requesting, Referring, Ordering).
  - servicing_provider_*: the provider or facility that will perform the service (Servicing, Rendering, Facility).
  - acuity: the marked priority option (e.g. Routine/Standard, Urgent/Expedited).
  - lob: line of business / plan type (e.g. Medicaid, Medicare, Commercial) or the plan name.
  - type_of_service: category of service (e.g. Outpatient, Inpatient, Home Health, DME, Physical Therapy).
  - place_of_service: the setting where service occurs (e.g. Home, Office, Outpatient Hospital).
  - diagnoses: every ICD-10 code listed (diagnosisCode).
  - procedures: one entry per procedure row: procedureCode (CPT/HCPCS), dateOfServiceStart,
    dateOfServiceEnd, numberOfVisits (visits/units requested).
